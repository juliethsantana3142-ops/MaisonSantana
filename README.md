# Maison Santana

Aplicación Android de tienda virtual de moda femenina (Kotlin + XML).

## Roles
- Comprador: inicio, detalle de producto, carrito, pago y perfil.
- Vendedor: gestión de productos.
- Administrador: gestión de usuarios y permisos.

## Transversal
Splash, registro con roles, login, huella (biometría) y recuperar contraseña.

## Tecnologías
Kotlin, XML, SharedPreferences, BiometricPrompt, fuentes personalizadas (Great Vibes, Inria Serif, Bree Serif).
